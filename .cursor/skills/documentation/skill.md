# Documentation Skill

## Purpose
Create and maintain clear, concise, and developer-friendly project documentation.

## Guidelines

- Keep documentation accurate, concise, and easy to maintain.
- Document the purpose and usage rather than obvious implementation details.
- Update documentation when APIs, configuration, setup, or architecture changes.
- Keep README documentation focused on:
  - Project overview
  - Tech stack
  - Prerequisites
  - Setup and configuration
  - Running the application
  - Testing
  - API overview
- Document APIs with:
  - Endpoint and HTTP method
  - Request/response
  - Validation
  - Status codes
  - Error scenarios
- Document important architectural and technical decisions.
- Use simple diagrams when they improve understanding.
- Prefer clear examples over lengthy explanations.
- Do not document secrets, credentials, or sensitive information.
