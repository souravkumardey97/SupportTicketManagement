# Review Code

Review the selected code against the project rules and identify actionable issues.

Check:

- Correctness and edge cases
- Java 21 and Spring Boot best practices
- Clean code and SOLID principles
- Layer separation and dependency injection
- API design and validation
- Exception handling
- Security concerns
- Database/query performance
- Transaction handling
- Logging
- Test coverage and test quality
- Maintainability and unnecessary complexity

For each issue provide:

- Severity: Critical / Major / Minor
- Location
- Problem
- Recommended fix

Do not modify code unless explicitly requested.

If no issues are found, state that clearly.
