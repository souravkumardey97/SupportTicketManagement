# Review Specification

Review the provided specification before implementation.

Check for:

- Clear and complete requirements
- Ambiguous or contradictory requirements
- Functional requirements and business rules
- API endpoints and contracts
- Request/response requirements
- Validation requirements
- Data and database requirements
- Security requirements
- Performance and scalability requirements
- Error and failure scenarios
- Important edge cases
- Missing requirements or dependencies

Return:

1. Clearly defined requirements
2. Ambiguities
3. Missing requirements
4. Contradictions
5. Edge cases
6. Technical concerns
7. Questions requiring clarification

Do not implement code during specification review unless explicitly requested.
